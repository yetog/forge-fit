# Forge Fit Golf - Color Palette

> Square Enix RPG-Inspired Design System
>
> Dark, immersive backgrounds with glowing accents, metallic highlights,
> and clear visual hierarchy inspired by Final Fantasy and Kingdom Hearts.
>
> Created: November 2026

---

## Design Philosophy

The Forge Fit Golf color system draws from the visual language of Square Enix RPGs:

- **Final Fantasy X Sphere Grid** - Color-coded skill sections, glowing nodes, connection paths
- **Final Fantasy XV** - Deep charcoal backgrounds, subtle blue accents, sleek modern feel
- **Kingdom Hearts** - State-based color changes (blue passive, orange/red active), glowing edges

The palette balances:
1. **Immersion** - Dark backgrounds for focus and RPG atmosphere
2. **Readability** - High contrast for outdoor/bright conditions
3. **Progression** - Visual distinction between locked, available, and mastered states
4. **Golf Context** - Muted greens and natural tones grounded in the sport

## 3. State Colors

### Node/Item States

| State | Color | Hex | Description |
|-------|-------|-----|-------------|
| **Locked** | Gray | `#4A4A4A` | Not yet available, requirements not met |
| **Available** | Skill Color + White Ring | (varies) | Can be unlocked, highlighted edge |
| **Unlocked/Active** | Skill Color (full) | (varies) | Learned/activated, filled appearance |
| **Selected** | Skill Color + Glow | (varies) | Currently focused, bright glow effect |
| **Mastered** | Skill Color + Gold Accent | (varies) | Fully completed, gold shimmer overlay |

### Interaction States

| State | Hex | Usage |
|-------|-----|-------|
| **Hover** | `rgba(255, 255, 255, 0.08)` | Subtle overlay on hover |
| **Focus** | `#4A90D9` + ring | Focus indicator ring |
| **Pressed** | `rgba(0, 0, 0, 0.12)` | Darken on press |
| **Disabled** | `#3A3A5C` | Grayed out, non-interactive |

## 8. Accessibility Notes

### Contrast Ratios (WCAG AA Compliance)

All text colors have been validated against the primary background (`#1A1A2E`):

| Text Color | Contrast Ratio | WCAG AA |
|------------|----------------|---------|
| Primary (`#FFFFFF`) | 15.5:1 | Pass (AAA) |
| Secondary (`#E0E0E0`) | 12.4:1 | Pass (AAA) |
| Muted (`#9E9E9E`) | 6.2:1 | Pass (AA) |
| Link (`#64B5F6`) | 6.8:1 | Pass (AA) |
| Success (`#81C784`) | 7.9:1 | Pass (AA) |
| Warning (`#FFCC80`) | 10.1:1 | Pass (AAA) |
| Error (`#FF8A80`) | 6.5:1 | Pass (AA) |
| Gold (`#FFD700`) | 10.8:1 | Pass (AAA) |

### Combinations to Avoid

| Combination | Issue | Alternative |
|-------------|-------|-------------|
| Muted text on elevated bg (`#9E9E9E` on `#3A3A5C`) | 3.2:1 - Fails AA | Use Secondary (`#E0E0E0`) |
| Disabled text (`#616161`) on any bg | Intentionally low | Acceptable for disabled states |
| Putting yellow (`#FDD835`) on white | 1.6:1 - Poor | Use dark variant or dark bg only |
| Short game purple (`#8E24AA`) as text on dark bg | 4.2:1 - Borderline | Use light variant (`#AB47BC`) |

### Recommendations

1. **Never use Disabled text (`#616161`) for actionable content**
   - Reserve for truly disabled/inactive elements only

2. **Skill colors should primarily be used for visual elements, not text**
   - Use them for node fills, progress bars, icons
   - For skill labels, use Primary or Secondary text colors

3. **Yellow (Putting) requires careful handling**
   - Always use on dark backgrounds
   - Consider using the dark variant (`#F9A825`) for better contrast

4. **Focus indicators must be clearly visible**
   - Use `#4A90D9` (Azure) with a 2-3px ring
   - Ensure 3:1 contrast against adjacent colors

5. **Glow effects are supplementary, not primary indicators**
   - Don't rely solely on glow to convey state
   - Pair with color change, icon change, or text

### Color Blindness Considerations

The skill tree uses a diverse palette that remains distinguishable for most forms of color blindness:

| Skill | Color | Deuteranopia | Protanopia | Tritanopia |
|-------|-------|--------------|------------|------------|
| Driving | Red | Appears olive | Appears olive | Appears red |
| Irons | Blue | Blue | Blue | Pink |
| Woods | Green | Yellow | Yellow | Green |
| Short Game | Purple | Blue | Blue | Pink |
| Putting | Yellow | Yellow | Yellow | Pink |
| Strategy | Orange | Yellow | Yellow | Pink |

**Mitigation strategies:**
- Each skill section uses unique iconography
- Labels accompany color indicators
- Progress percentages provide numerical context
- Node shapes can vary by skill type
