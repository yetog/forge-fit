## Implementation Notes

### Storage
```typescript
interface Achievement {
  id: string;
  name: string;
  description: string;
  tier: 'minor' | 'standard' | 'major' | 'legendary';
  xpReward: number;
  icon: string;
  hidden: boolean;
  unlockedAt?: string;
  progress?: number; // For progress-based achievements
  target?: number;
}
```

### Display States
- **Locked:** Grayed out, shows condition (unless hidden)
- **In Progress:** Shows progress bar (e.g., "7/10 sessions")
- **Unlocked:** Full color, shows unlock date
- **Hidden Locked:** Shows "???" until unlocked

### Unlock Animation
1. Badge slides in from bottom
2. Particle burst
3. XP award floats up
4. Toast notification with achievement name
