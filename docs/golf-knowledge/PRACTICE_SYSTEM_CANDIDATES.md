## A. Deliberate-practice protocol

1. Select **one outcome** to improve (for example, consistent contact).
2. Establish a comparable baseline with club, ball/lie, target, swing length and sample size.
3. Record contact (clean/fat/thin/top), ball start (left/center/right), curve (left/straight/right), and carry only if actually known.
4. Choose **one** hypothesis. Write what observation would support or falsify it.
5. Change one coach-approved cue or drill while holding setup/club/target reasonably constant.
6. Repeat a matched sample; report **counts**, not just the best strike.
7. Remove the cue and retest to see whether the effect persists.
8. Save a brief reflection: what changed, evidence quality, next experiment.
9. Seek instructor assessment if the cause remains ambiguous or conflicting.

For very small samples (e.g. five shots), describe trends as **preliminary**, not a demonstrated motor change. Improvement must survive repeat sessions before mastery is awarded.

## D. Swing-plane hoop teaching concept

**Source:** Oct 25–26 conversation excerpts. User described hoop-like **tilted semicircle axes** and wanted a visual relationship across club lengths.

- Show several translucent, individually labeled hoops on shared ground and target orientation.
- Relative club-dependent plane orientation is a teaching metaphor, not a perfect path trace or a launch-monitor prediction.
- Include separate visual controls or legend for **swing plane, horizontal club path, attack angle and release**.
- Do not use arbitrary per-club plane angles as a measured personal swing profile.
- Preserve the original diagram request in asset-recovery queue. Any new educational graphic requires source checking and design review.

## F. Guardrail against practice sabotage

Do not change grip, stance distance, wrist release, knee mechanics and swing plane in response to one poor shot. After a miss, label the result, continue the planned sample, compare **patterns**, then test one variable. If a change leads to inconsistent results, revert and seek coached feedback.
