## Key Concepts

### The 5-Part Swing Model
```
SPACE → CHARGE → DROP → TURN → BALANCE
```

### The 5-Checkpoint Pre-Shot
```
Target → Build → Rehearse → See → Finish
```

### Weekly Philosophy
| Day | Purpose |
|-----|---------|
| Monday | Understand |
| Tuesday | Score |
| Wednesday | Generalize |
| Thursday | Calibrate |
| Friday | Perform |
