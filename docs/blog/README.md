## Publishing

These posts can be published to multiple platforms:

### Portfolio Site
Copy the markdown content to the portfolio blog section at `zaylegend.com/blog`

### Medium
1. Create a new story on Medium
2. Import the markdown or copy/paste content
3. Add images from `/images/blog/`
4. Add tags: `UX Design`, `Gaming`, `Golf`, `Product Design`

### Dev.to
1. Create a new post on dev.to
2. Use the markdown directly (Dev.to supports frontmatter)
3. Add tags: `ux`, `design`, `gaming`, `beginners`
